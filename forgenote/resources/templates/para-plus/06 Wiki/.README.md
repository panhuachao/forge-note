# 06 Wiki

## 定位

长期稳定的结构化知识百科。

## 放入标准

**应该放入**：
- 按主题组织的概念解释
- 领域知识
- 术语表
- 人物 / 地点 / 事件条目
- 追求结构化与长期维护的条目

**不应放入**：
- 临时性的思考（应放入 00 灵感库）
- 个人方法论（应放入 02 资产）
- 时效性强的内容

## 流转规则

- 由 00 灵感 / 01 项目 / 02 资产提炼沉淀而来
- 是知识的"最终形态"
- 与资产、项目、技能建立广泛双向链接
- 持续维护，更新到最新认知

## Wiki 条目特征

- 客观、中立、可验证
- 与外部资源建立 [[链接]] 引用
- 多个相关条目相互链接形成知识网络
