# 01 项目

## 定位

有明确目标与截止日期的正在进行事项。

## 放入标准

**应该放入**：
- 当前在做的事（如"开发 AI 知识库工具"、"做一期短视频"）
- 项目目标、卡点、过程记录、复盘
- 有 deadline 的工作

**不应放入**：
- 没有具体目标的长期关注（应放入 02 资产 / 06 Wiki）
- 纯粹的思考记录（应放入 00 灵感库）

## 流转规则

- 项目完成后整体移入 04 归档
- 项目中验证有效的方法论/素材可提炼至 02 资产
- 项目中的关键决策、原则可移入 06 Wiki

## 项目模板字段

每个项目笔记应包含：
- 目标（明确可衡量）
- 截止日期
- 当前状态（进行中 / 阻塞 / 已完成）
- 卡点
- 复盘（完成后）

## 常见问题

**Q：项目与资产的界限？**
A：项目是"在做的事"，资产是"做完沉淀下来的方法论"。
