> 你可以完全自由编辑此文件，保存后 AI 的归纳/链接/锻造推荐将立即生效（无需重启 APP）。

## 一、知识库整体定位

- **知识库名**：{{kbName}}
- **创建日期**：{{date}}
- **用户身份**：内容创作者 / 知识工作者
- **核心目标**：把碎片化灵感锻造成可复用的知识资产。

## 三、核心设计思想

1. **单向流向**：灵感只能从灵感库加工成卡片后才能流到项目或长期关注，不能倒灌。
2. **只抽增量**：新卡片只处理新的增量信息，不重复加工已有内容。
3. **行动导向**：按"我要用它做什么"而非"它是关于什么"分类。
4. **知识卡片四铁律**：原子性、可行动、可证伪、诚实。

## 四、AI 归纳推荐规则

当用户新建/导入笔记时，AI 应根据以下顺序判断归档目录：

1. **内容匹配度**：根据笔记内容与各目录 README 的语义相似度排序。
2. **行动性优先级**：有明确行动 > 思考记录 > 资料收藏。
3. **流向规则**：
   - 已完成项目 → 推荐归档到 04
   - 验证有效的方法论 → 推荐移入 02
   - 不确定放哪 → 默认推荐 00 灵感库，提示"建议后续加工"
4. **置信度阈值**：低于 0.4 的推荐不应展示给用户，改为提示"建议人工判断"。

## 五、AI 链接推荐规则

1. **语义相似度**：基于向量相似度（top 20 候选）。
2. **流向加权**：
   - 灵感库 → 01/02/06 流向加分
   - 资产 → Wiki 引用加分
3. **分级输出**：
   - **强相关**（相似度 > 0.7）：直接推荐
   - **流向建议**：符合模板定义的流向规则
   - **弱相关**（相似度 0.4-0.7）：仅作为提示
4. **去重**：当前笔记已有的 [[xxx]] 链接不再推荐。

## 六、知识卡片锻造规则

将灵感库笔记锻造为知识卡片时，输出必须包含：

1. 标题（一句话，原子化）
2. 核心观点（一句话）
3. 详细内容（2-5 段）
4. 可行动项（每条以 - [ ] 开头，至少 1 条）
5. 验证标准（可证伪）
6. 状态：L1（初始） / L2（用出效果） / L3（跨场景验证）
7. 来源：原灵感笔记的 [[wiki 链接]]

## 七、AI 禁止事项（重要）

1. **不得自动移动文件**：所有目录移动必须由用户确认。
2. **不得静默插入链接**：所有链接插入必须经用户勾选。
3. **不得编造笔记内容**：回答中提到的笔记必须真实存在于知识库。
4. **不得删除文件**：用户未确认前不删除任何笔记。
5. **不得跨知识库操作**：只能操作当前激活的知识库。

## 八、降级策略

当本地模型不可用且未配置远端模型时：

- 归纳推荐：使用 TF-IDF 与目录 README 关键词重合度。
- 链接推荐：使用标题余弦相似度 + 同目录优先。
- 卡片锻造：基于笔记大纲拆分为多张草稿卡片。
- RAG 问答：返回 top 5 相关笔记的标题与片段，不生成总结。
