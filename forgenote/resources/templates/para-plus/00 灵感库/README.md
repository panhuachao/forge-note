# 00 灵感库

## 定位

知识的入口，临时收件箱。

## 放入标准

**应该放入**：
- 一闪而过的想法、思考碎片
- 读到的好句子、好观点
- 聊天中突然产生的灵感
- 待验证的假设、问题
- 日记、随笔
- 不确定放哪的内容

**不应放入**：
- 已验证的方法论（应放入 02 资产）
- 有明确目标的事项（应放入 01 项目）
- 完整的外部文章（应放入 03 外部资源）

## 流转规则

**单向流向起点**：
- 加工为知识卡片 → 流转至 01 项目 / 02 资产 / 06 Wiki
- 加工后的原笔记标记"已加工"或移入 04 归档

**禁止**：其他目录内容倒灌入灵感库。

## 常见问题

**Q：灵感太多怎么办？**
A：定期（如每周）批量处理灵感库，使用「锻造知识卡片」功能。

**Q：如何区分灵感和外部资料？**
A：灵感是你自己产生的；外部资料（文章、书摘等）放入 03 外部资源。
