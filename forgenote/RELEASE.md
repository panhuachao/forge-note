# 锦囊笔记 ForgeNote 版本更新记录

本文件按版本记录 ForgeNote 的更新说明，最新版本在最上方。

---

## v1.0.0

**发布日期**：2026-08-26

### 新增
- 笔记页左侧新增「新建笔记」「新建文件夹」快捷操作区。
- 新增「AI 诊断」入口：对整体知识库进行诊断（缺失双链建议、笔记归属纠错、目录结构补全），支持用户逐一确认后由 AI 自动修正。
- 应用内自动更新（electron-updater）：支持静默检查更新与「设置」页手动更新/安装。

### 优化
- 灵感页：使用公共标题组件，页面宽度自动占满；右侧内容区改为白底以突出内容。
- 灵感页「存为笔记」直接唤起快速笔记弹窗并自动填充内容。
- Markdown 中 `---` 渲染为分隔划线（不再作为段落终止符）。
- 主菜单布局：灵感图标移至「快速笔记」之后归组；笔记图标换为 folder；知识图谱移至笔记之后，图标换为 share。
- 知识图谱右侧目录筛选仅提取一级目录。

### 修复
- `App.tsx` / `SettingsPage.tsx` 对 `window.forge.app` 增加判空与 noop 防御，避免旧 preload 构建下因 `app` 段缺失导致白屏崩溃。

## v1.1.0

**发布日期**：2026-08-28

> 自 v1.0.0 以来的主要更新，聚焦 AI 能力增强、双链/元数据可靠性修复与多项体验优化。

### 新增
- **知识库「闲逛」功能**：笔记左侧主菜单新增闲逛入口，随机发现知识库内有价值的（可跨笔记关联的）知识点，以知识卡片方式呈现，每次提供 3 张卡片，让用户持续感知知识库价值。
- **多 Agent 协作**：引入多 Agent 架构，内置多种角色 Agent 可协同完成复杂任务；原有内置 Agent 现已支持作为 Skill 被调用。
- **用户画像记忆功能**：系统可记忆用户画像与偏好，使 AI 回答更贴合个人背景。
- **目录 / 笔记关注功能**：支持关注指定目录或笔记，便于聚焦与持续跟踪。
- **笔记链接跳转查看**：在 AI 会话或笔记中点击 `[[笔记链接]]`，可查看目标笔记基本信息并支持双击直接打开对应笔记。
- **AI 未设置引导**：当模型 / API 等未配置时，给出明确引导提示，降低上手门槛。
- **多媒体文件支持**：知识库内多媒体文件（图片等）的引用与管理方案落地。

### 优化
- **Markdown 与 FrontMatter 标准化**：对 Markdown 解析与 FrontMatter 读写进行重构，统一规范，提升跨设备重新索引与元数据的可靠性。
- **RAG 检索增强**：重构存储层并引入 RAG 能力，提升问答与检索质量。
- **AI 调用链路重构**：重构 AI 服务调用链路，支持 MCP 调用、统一调用逻辑与多 Agent 调度。
- **标签体验修复**：修复排序功能与标签索引列显示不全问题；修复标签列表中出现未写入笔记 frontmatter 的多余标签。
- **首页问答跳转**：修复首页问答结果点击跳转无响应问题。
- **默认进入知识库笔记页**：修复默认页与笔记查询出现重复笔记的问题。

### 修复
- **双链更名同步（重要）**：重命名笔记时，自动将其他笔记中指向该笔记的 `[[旧名]]` 同步更新为 `[[新名]]`（保留别名），避免旧双链失效。
- **重命名唯一性校验（重要）**：由于双链基于笔记名（basename）命名空间，重命名时校验新名称在当前知识库内唯一，重名将提示用户改用其他名称，避免链接歧义。
- **创建时间稳定性**：修复因 `atomicWrite`（writeFile + rename）重置 inode 导致 `createdAt` 丢失、使「创建时间」与「最后更新」被错误显示一致的问题；现创建时间固化于 FrontMatter 并全程保留。
- **自动更新**：修复自动更新下载后无法重启安装的问题；修复正式打包启动无窗体内容、macOS 分架构打包与 notarize 配置等问题。
