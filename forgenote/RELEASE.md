# 锦囊笔记 ForgeNote 版本更新记录

本文件按版本记录 ForgeNote 的更新说明，最新版本在最上方。

---

## v1.5.0

**发布日期**：2026-09-03

> 自 v1.4.0 以来的主要更新：上线**主题学习**模块——输入任意主题后由 AI 拆解为「模块 / 文章」的学习路径并逐篇生成系列文章，内置多种学习模式、实时进度反馈与磁盘持久化，生成完成后可在阅读视图逐篇浏览并一键转存为知识库笔记；同时修复主题学习中部分特殊格式文章导致阅读页一直加载、渲染进程内存泄漏的问题，并重构阅读页渲染以彻底规避内存风险。

### 新增

- **主题学习**：主菜单新增「主题学习」入口（🎓 图标），将单一主题系统化拆解为「模块 / 文章」的系列学习内容。
  - **两步生成流程**：第一步由 AI 将主题规划为若干模块（栏目）及每篇的文章大纲，第二步按大纲逐篇生成 Markdown 正文；全程可中断、可恢复，已生成内容实时可见。
  - **多种学习模式**：内置「普通 / 学习 / 专家」三种模式，分别面向通俗概览、体系化深学、严谨研究；另提供「姜胡说快速学习」固定方法论模式，按「锁定 20% 核心 → 排除可延迟枝节 → 类比理解 + 一周实战 → 直击第一性原理」四步快速入门一个陌生领域。
  - **实时进度反馈**：生成过程按阶段实时推送进度（规划目录架构 → 逐篇生成 → 完成），并逐篇标记待生成 / 生成中 / 已完成状态。
  - **目录 / 文件持久化**：每个学习主题以独立目录存储（`index.json` 存目录与概要、每篇文章一个 `.md`），单篇生成完成即落盘，失败或中断不丢失已产出内容。
  - **阅读视图**：生成完成后自动进入学习页，左侧为「模块 / 文章」大纲、右侧为 Markdown 预览，可随时切换任意文章浏览。
  - **一键转存为笔记**：阅读页可将当前文章一键「添加到笔记」，自动预填为知识库笔记草稿，再由 AI 整理归档。
  - **历史学习记录**：输入页展示历史学习记录与完成状态，支持「全部记录」宫格视图，可重新进入阅读或删除。

### 优化

- **AI 请求超时兜底与自动重试**：模型请求增加 90 秒总超时，服务端半响应 / 卡住时不再无限等待；对网络瞬时抖动（断连、超时等）按指数退避自动重试，非瞬时错误（鉴权失败等）立即失败，不空耗等待。
- **主题学习阅读页内存安全重构**：阅读页改为「按需读取正文 + 即用即弃」模式——不再缓存原文与已渲染 HTML、不做后台预取、不延迟排队解析；任意时刻仅保留「当前选中文章」的一次读取与一次渲染，切走 / 卸载即丢弃，从源头杜绝反复切换文章与多会话场景下渲染进程内存持续增长（此前曾因此出现 OOM）。

### 修复

- **主题学习部分文章一直加载、无法显示正文（重要）**：部分文章内容包含「孤立表格行」（形如 `| a | b |`，其后缺少分隔行时不被识别为表格），旧解析逻辑会让该类行落入段落后又立即终止，导致解析循环空转、阅读页卡在加载态、渲染进程内存持续上涨；现已对不完整表格结构容错，按普通文本展示，解析不再卡死。
- **主题学习生成健壮性**：强化模型返回解析的容错（剥离代码块包裹、清理尾随逗号 / 中文引号、截断补齐等），并修正网络错误提示语，便于区分「配置问题」与「网络抖动」。

## v1.4.0

**发布日期**：2026-09-01

> 自 v1.3.0 以来的主要更新：左侧视图切换新增「笔记列表」视图，可将知识库以「全部笔记平铺」的方式浏览，默认按更新时间倒序排列，便于快速纵览与定位笔记。

### 新增

- **知识库「按笔记查看」视图**：左侧视图切换区在「标签」图标之前新增「笔记列表」图标（📁 知识库 → 📝 笔记列表 → 🏷 标签），点击后左栏从目录树切换为笔记列表视图。
  - **全部笔记平铺**：检索知识库内所有 `.md` 笔记并平铺展示，不显示目录层级，一眼纵览整个知识库。
  - **默认按更新时间倒序**：列表默认按笔记「修改时间」倒序排列（最近更新的在最上方）；支持在视图顶部切换「修改时间 / 名称」排序。
  - **笔记信息**：每条显示笔记标题、所属目录与更新时间；点击即打开该笔记并切回笔记编辑视图。
  - **自动刷新**：监听文件变更事件，笔记新建 / 重命名 / 移动后列表自动更新。

## v1.3.0

**发布日期**：2026-08-31

> 自 v1.2.0 以来的主要更新：上线**插件系统**、**笔记编辑区 AI 右击菜单**（改写/续写/翻译）、**外部网络搜索 MCP**，笔记 AI 对话改为**逐字流式回复**；同时修复输入法组合态回车误发送、插件预览不实时等关键缺陷。

### 新增

- **插件系统**：新增插件模块与插件管理页面，支持以插件形式扩展锦囊笔记的能力。
  - **笔记预览开放权限**：插件可访问笔记预览能力，便于围绕笔记内容开发扩展功能。
- **笔记编辑区 AI 右击菜单**：在编辑区选中文本后右键，可直接「改写 / 续写 / 翻译」，由 AI 基于上下文即时处理，无需切换到对话框。
- **外部网络搜索 MCP**：新增 `open-websearch` 等外部网络搜索 MCP 工具，使 AI 在对话与智能体中可实时检索联网信息，补足本地知识库之外的资料。
- **笔记 AI 对话流式回复**：笔记侧栏的普通问答由「等待整段返回」改为**逐 token 流式输出**，回复随生成实时呈现，交互更顺畅（智能体模式此前已支持流式）。
- **图片轮播**：支持在笔记中以轮播形式浏览图片（已有能力的增强）。
- **HTML 宣传网页**：新增对外宣传网页（`html/` 目录），用于产品介绍与分发。

### 优化

- **插件页面**：重构插件管理页面交互，信息展示与操作更清晰。
- **图片轮播**：优化轮播浏览体验。

### 修复

- **输入法组合字母回车自动发送（重要）**：使用中文 / 日文等输入法组字（composition）过程中按下回车，会被误判为「发送」导致半截拼音被发出；现正确区分组合态与确认态，组字期间回车不再触发发送。
- **open-websearch 最大工具轮次**：修复外部网络搜索在工具调用轮次上限下提前终止、无法完成检索的问题。
- **Agent 定义**：修正智能体（Agent）定义，确保工具调用与人格注入符合预期。
- **插件预览无法实时更新**：修复插件涉及笔记预览时，源内容变更无法实时刷新预览的问题。

## v1.2.0

**发布日期**：2026-08-29

> 自 v1.1.0 以来的主要更新：新增**笔记版本管理**与**知识库体检**两大能力，AI 修改笔记全面接入「先建议、后确认」安全机制，并修复了笔记编辑光标跳动、双链误判失效等关键缺陷。

### 新增

- **笔记版本管理**：为笔记提供完整的历史版本能力。
  - **自动留存**：停止编辑 3 分钟后自动记录一个版本，无需手动保存。
  - **手动打点**：可随时保存当前版本并附备注。
  - **关键操作存档**：AI 修改、版本恢复、移动/重命名前自动存档，误操作可回溯。
  - **版本比对**：任意版本之间、版本与当前内容之间的逐行 diff，增删行按颜色区分。
  - **一键恢复**：恢复前会先把当前内容存为一个版本，因此恢复本身也可撤销。
  - **自动清理**：7 天内全保留、30 天内每天保留 1 份、更早每周保留 1 份；单笔记上限 50 个版本，总占用超 200MB 时按最旧优先淘汰。
- **知识库体检**：「诊断」页新增体检报告，无需配置 AI 模型即可运行。
  - 检查失效双链、重复内容、孤立笔记、空目录、稀疏标签、目录结构、长期未更新共 7 类问题。
  - 给出综合健康分与统计概览，问题项可一键执行整理建议。
- **AI 批量任务**：支持批量修改、批量移动、批量打标签；执行前逐条展示差异预览，执行后给出成功/失败清单并支持整体回滚。
- **执行后验证与回滚**：AI 修改笔记落盘后自动回读校验是否真的生效，未达预期时提示一键回滚。
- **主动建议**：应用启动后自动检查知识库体检结果并轻提示一次，同一问题 7 天内不重复打扰。
- **AI 修改确认机制**：AI 笔记对话中需要修改笔记时，先展示修改建议与 diff 预览，用户确认后才落盘，避免 AI 直接改写内容。
- **知识库级 AI 工具**：新增统计、重复检测、孤立笔记、标签体系、结构评审、过期内容 6 项只读工具，让 AI 能对知识库「全局把脉」而非仅处理单篇笔记。

### 优化

- **AI 调用链路收敛**：原先分散在各处的 11 处 AI 调用统一收敛到统一入口，使 Prompt 治理、流式输出、用量统计、安全确认等机制能一致覆盖全部 AI 能力。
- **会话持久化**：AI 对话上下文落盘保存，应用重启后仍可延续之前的对话。
- **统一流式输出**：合并多套并存的流式实现，交互与错误处理更一致。
- **属性面板版本入口**：笔记右侧属性面板新增「版本」一栏，显示版本数量与最近保存时间，点击可直接打开版本历史。

### 修复

- **笔记编辑光标自动跳到第一行（重要）**：编辑笔记时，自动保存与文件变更事件形成回环，导致编辑器内容被数百毫秒前的旧快照整体覆盖、光标被重置到开头；同时可能造成刚输入的内容丢失。现能正确区分「自己的保存」与「外部/AI 的修改」。
- **双链误判为失效链接**：当 wiki 链接显式写了 `.md` 后缀、且目标笔记位于子目录时，会被错误判定为失效链接。现后缀不再影响匹配。
- **自动版本不生成**：版本调度定时器被标记为主进程空闲可跳过，导致停止编辑后迟迟不生成自动版本。现改为按笔记独立计时，最后编辑后 3 分钟准时记录。
- **自动更新**：修复相同版本号下，不同客户端下载更新包的校验问题。

## v1.1.0

**发布日期**：2026-08-28

> 自 v1.0.0 以来的主要更新，聚焦 AI 能力增强、双链/元数据可靠性修复与多项体验优化。

### 新增
- **知识库「闲逛」功能**：笔记左侧主菜单新增闲逛入口，随机发现知识库内有价值的（可跨笔记关联的）知识点，以知识卡片方式呈现，每次提供 3 张卡片，让用户持续感知知识库价值。
- **多 Agent 协作**：引入多 Agent 架构，内置多种角色 Agent 可协同完成复杂任务；原有内置 Agent 现已支持作为 Skill 被调用。
- **用户画像记忆功能**：系统可记忆用户画像与偏好，使 AI 回答更贴合个人背景。
- **目录 / 笔记关注功能**：支持关注指定目录或笔记，便于聚焦与持续跟踪。
- **笔记链接跳转查看**：在 AI 会话或笔记中点击 `[[笔记链接]]`，可查看目标笔记基本信息并支持双击直接打开对应笔记。
- **AI 未设置引导**：当模型 / API 等未配置时，给出明确引导提示，降低上手门槛。
- **多媒体文件支持**：知识库内多媒体文件（图片等）的引用与管理方案落地。

### 优化
- **Markdown 与 FrontMatter 标准化**：对 Markdown 解析与 FrontMatter 读写进行重构，统一规范，提升跨设备重新索引与元数据的可靠性。
- **RAG 检索增强**：重构存储层并引入 RAG 能力，提升问答与检索质量。
- **AI 调用链路重构**：重构 AI 服务调用链路，支持 MCP 调用、统一调用逻辑与多 Agent 调度。
- **标签体验修复**：修复排序功能与标签索引列显示不全问题；修复标签列表中出现未写入笔记 frontmatter 的多余标签。
- **首页问答跳转**：修复首页问答结果点击跳转无响应问题。
- **默认进入知识库笔记页**：修复默认页与笔记查询出现重复笔记的问题。

### 修复
- **双链更名同步（重要）**：重命名笔记时，自动将其他笔记中指向该笔记的 `[[旧名]]` 同步更新为 `[[新名]]`（保留别名），避免旧双链失效。
- **重命名唯一性校验（重要）**：由于双链基于笔记名（basename）命名空间，重命名时校验新名称在当前知识库内唯一，重名将提示用户改用其他名称，避免链接歧义。
- **创建时间稳定性**：修复因 `atomicWrite`（writeFile + rename）重置 inode 导致 `createdAt` 丢失、使「创建时间」与「最后更新」被错误显示一致的问题；现创建时间固化于 FrontMatter 并全程保留。
- **自动更新**：修复自动更新下载后无法重启安装的问题；修复正式打包启动无窗体内容、macOS 分架构打包与 notarize 配置等问题。

## v1.0.0

**发布日期**：2026-08-26

### 新增
- 笔记页左侧新增「新建笔记」「新建文件夹」快捷操作区。
- 新增「AI 诊断」入口：对整体知识库进行诊断（缺失双链建议、笔记归属纠错、目录结构补全），支持用户逐一确认后由 AI 自动修正。
- 应用内自动更新（electron-updater）：支持静默检查更新与「设置」页手动更新/安装。

### 优化
- 灵感页：使用公共标题组件，页面宽度自动占满；右侧内容区改为白底以突出内容。
- 灵感页「存为笔记」直接唤起快速笔记弹窗并自动填充内容。
- Markdown 中 `---` 渲染为分隔划线（不再作为段落终止符）。
- 主菜单布局：灵感图标移至「快速笔记」之后归组；笔记图标换为 folder；知识图谱移至笔记之后，图标换为 share。
- 知识图谱右侧目录筛选仅提取一级目录。

### 修复
- `App.tsx` / `SettingsPage.tsx` 对 `window.forge.app` 增加判空与 noop 防御，避免旧 preload 构建下因 `app` 段缺失导致白屏崩溃。
